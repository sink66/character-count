# Character Count

`txt` と `md` ファイルの文字数を数えて、VS Code のステータスバー左側に表示する拡張機能です。

## Features

- アクティブな `.txt` / `.md` ファイルの文字数をリアルタイム表示
- ステータスバー左側に常時表示
- 絵文字や結合文字もできるだけ自然な単位でカウント

## Usage

1. この拡張を起動した状態で `.txt` または `.md` ファイルを開きます。
2. 画面下部のステータスバー左側に文字数が表示されます。
3. ファイル内容を編集すると表示が自動更新されます。

## Notes

- 対象は拡張子が `.txt` と `.md` のファイルのみです。
- それ以外のファイルではステータスバー項目は非表示になります。
